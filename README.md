# Siong Interior & Builder Website

Sleek responsive static website for Vercel/GitHub.

## Upload Steps

1. Delete old `src`, `public`, `tailwind.config.js`, `postcss.config.js`, `vite.config.js`.
2. Upload all files in this folder to GitHub root.
3. Commit changes.
4. Redeploy on Vercel.

## Vercel Settings

Build Command: `npm run build`  
Output Directory: `dist`
